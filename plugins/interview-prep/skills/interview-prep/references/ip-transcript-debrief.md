# Prior-Stage Transcript Debrief

Runs as **Phase 1.5**, between company research and question generation,
whenever the user provides a recording, transcript, or notes from a
**completed** interview/meeting stage for this same process. This is what
makes multi-round prep cumulative instead of starting cold every round —
carry forward what was actually said, don't re-derive it from public
research alone.

## When this runs

- User pastes/attaches a transcript, recording, or their own notes from a
  prior round ("here's the call from Tuesday", "I recorded the first
  interview, here's the transcript").
- Skipped entirely if this is round one with nothing prior — go straight
  from Phase 1 (Company Intel Research) to Phase 2.

## Method — the reconciliation loop

Take everything already believed about the company/role (from this
session's own Phase 1 research, or from a prior round's dossier if one
exists) and cross-check it against the transcript. Sort every finding into
exactly one of three buckets — don't skip the sort, it's what makes this
useful rather than just a summary:

1. **Confirmed, no change needed.** Something already assumed or
   researched that the transcript independently backs up. Worth noting
   briefly, not dwelling on.
2. **Corrected — this matters.** Something the transcript contradicts —
   a wrong figure, a wrong assumption about ownership/timeline/scope, a
   misread on who owns a decision. Flag explicitly what changes as a
   result, especially anything that changes *sequencing* (e.g. an exit
   timeline that turns out to be 12-18 months rather than 3-5 years
   changes what the first 90 days should prioritize far more than it
   changes any single STAR story). Don't just log the correction — say
   what it means for the next round's prep.
3. **Genuinely new — wasn't in anything researched.** Information that
   only exists because someone said it in the room: an internal metric,
   an unstated priority, a name of someone else in the process, a real
   pain point. This is usually the highest-value output of this phase —
   it's exactly the material public research can never produce.

## Transcription hygiene

Auto-transcribed recordings misspell names and mishear words routinely.
Before treating a name or figure as fact, cross-reference it against
context clues already known (email domains, LinkedIn names from Phase 1,
action items that only make sense if attributed to a specific person).
Flag anything genuinely ambiguous rather than guessing silently.

## Output

1. The three-bucket reconciliation, in that order, tight — this is a
   working debrief, not a transcript summary.
2. **What changes for the next round:** a short, explicit list — updated
   STAR-story bridges if the role's priorities shifted, updated smart
   questions (a question already answered in this transcript should never
   be asked again — drop it and replace with a sharper follow-up that
   builds on the answer given), and any updated posture-by-round guidance
   (see `ip-question-bank.md`) if this transcript reveals the process has
   moved further/faster than assumed.
3. **Written back into the dossier** (`ip-dossier-template.md`'s "Round
   History" section) if one exists for this application — append, don't
   overwrite, so the full round-by-round history stays visible.

## Escalating question posture with confirmed traction

If a transcript shows the conversation going deep and well (detailed
technical/strategic exchange, clear mutual interest), the next round's
smart questions (Phase 4) can afford to be sharper than the round-1
defaults in `ip-question-bank.md` — including taking an explicit,
falsifiable position rather than only asking open questions:

> Instead of "how do you think about X?", try "my read is X — where am I
> wrong?" A stated, correctable position that turns out right builds more
> credibility than a safe open question; if it turns out wrong, being
> corrected in the room is still a good outcome — it means real signal
> exchange happened. Reserve this for rounds where the transcript already
> shows genuine depth, not round one.

## Late-stage / diligence-level rounds

If the transcript or context indicates this has moved into final-round,
executive, or formal-offer-adjacent territory (references to next steps,
document requests, references, contracts), see
`references/ip-diligence.md` for the document/question checklist that
applies at that stage — don't keep using round-one HR-screen framing this
late in the process.
