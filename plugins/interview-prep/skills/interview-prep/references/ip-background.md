## Discovery (when no story fits)

If Phase 3 flags a likely question with no matching story above, ask once,
briefly:

> "I don't have a strong story for [competency] in what I've got on file —
> did you do something like that at [most relevant company]? Even a rough
> Situation/Action/Result in a sentence each is enough to shape an answer."

If confirmed, use it for this session and append it to this file under the
right competency heading so future sessions don't re-ask.
